# PORTAL DE MATRÍCULAS

quero criar um sistema com login e senha, objetivo desse sistema é poder criar formularios personalizados e publicar com links publicos.

preciso tbm que, nesse sistema, eu possa configurar da forma que eu quiser impressores com dados de cada preenchimento e disponibilizar para pessoas devidamente autorizadas realizarem as impressores.

Cada formulario precisará ser´separadao por ESCOLA e cada escola tem uma sequencia de ID (Personalizado), esse ID é de extrema importancia para identificar cada cadastro.

Tbm preciso de uma listagem onde usuarios autorizados poderá editar ou acrescentar alguns dados necessario aquele cadastro atraves do ID.

Tbm preciso criar permissoes de usuarios como criar, editar e excluir alguns desses recursos
